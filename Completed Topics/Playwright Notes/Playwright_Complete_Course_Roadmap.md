## 🧭 How to Use This Roadmap

Use this file as your **master checklist** while following the Udemy
course.

### The learning rule

For every lecture:

1.  🎥 **Watch** the lecture.
2.  🧑‍💻 **Code along** with the instructor.
3.  ⌨️ **Close the video and reproduce it from memory.**
4.  🧪 **Change the example** --- don't only copy it.
5.  📝 **Write short notes**: definition → syntax → when to use → common
    mistake.
6.  ✅ Mark the topic complete only when you can explain and implement
    it yourself.

### Recommended cycle

``` text
Watch → Understand → Code Along → Rebuild → Modify → Practice → Explain → Mark Complete
```


### 🧠 Timeout model

Know the difference between:

  Timeout             Purpose
  ------------------- ----------------------------------------
  Action timeout      Time allowed for an action
  Assertion timeout   Time for an assertion to become true
  Test timeout        Maximum time for the entire test
  Global timeout      Maximum time for the complete test run
